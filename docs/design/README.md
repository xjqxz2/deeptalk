## 2. 每张图的结构

- 顶部：设计图标题 + 一句话设计意图 + 编号 + 规格（1440×900）。
- 左侧：1440×900 的高保真界面，编号 1–6 的圆点标注对应右侧说明。
- 右侧「设计说明」栏：编号条目（布局 / 组件 / 交互 / 状态）、设计令牌、落地约定。
- 所有标注都落在界面边缘或留白处，不遮挡控件本身。

## 3. 画板与栅格

- 画板 1800×1080；界面视口 1440×900，圆角 20，投影 `0 14 26 rgba(16,24,40,.09)`。
- 对话页：侧栏 280，内容列 704（空态 752），顶栏 64。
- 后台：侧栏 240，内容区左右留白 32，卡片间距 16 / 20。
- 认证页：左侧品牌区 620 + 右侧表单区 820，表单宽 380。

## 5. 交互约定（摘要）

1. 对话：Enter 发送 / Shift+Enter 换行；生成中切「停止生成」，Esc 可中断，已输出内容保留。
2. 会话：按今天 / 7 天 / 30 天分组；切换会话不打断正在生成的回答。
3. 后台：关闭厂商开关、限制登录、删除账号均二次确认；Key 只写不读。
4. 账号：登录失败统一提示，连续 5 次锁 10 分钟；注册成功即登录，无验证邮件。
5. 响应式：<1024 对话侧栏收为 64px，认证页隐藏品牌区。

## 6. 生成方式

```bash
node scripts/design/design-01-chat-empty.mjs      # 逐个生成 SVG
node scripts/design/render-design.mjs docs/design/*.svg
```

组件与令牌在 `scripts/design/design-lib.mjs`（设计说明栏、通用控件）、`admin-lib.mjs`（后台壳）、`auth-lib.mjs`（认证页）。
