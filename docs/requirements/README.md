# DeepTalk MVP · 需求图说明（v0.3）

> 首轮评审用需求图。已上传到「项目自动化助手」，**尚未设为开发依据**；确认后再进入实现。

## 1. 产品定位

DeepTalk 是一个面向 C 端用户的 AI 对话产品：

- 用户使用**邮箱 + 密码**注册和登录，不发送验证邮件，不做邮箱验证。
- 注册成功即登录，直接进入自己的对话空间。
- 每个用户的数据、会话与用量互相隔离，不存在租户层级。
- 平台管理员配置上游模型厂商、管理用户与额度。
- 用户不接触任何 API Key；上游厂商 Key 只存在服务端。
- 首个注册账号为平台管理员，其余为普通用户。

> 原“租户 API Key”已从 C 端 Web 产品中移除。后台只保留管理员配置的上游厂商 Key。若未来需要给用户发放开发者 API Key，单列为 P1，不混入主流程。

## 3. MVP 范围（P0）

### 账号

- 邮箱 + 密码注册；注册成功即登录，无邮箱验证、无验证邮件。
- 邮箱不区分大小写且唯一；密码至少 8 位，包含字母与数字。
- 首个注册账号为平台管理员；其余均为普通用户。
- 登录、退出、修改密码；会话 HttpOnly Cookie，默认 7 天。
- 登录失败统一提示；连续 5 次失败锁定 10 分钟。
- 无邮件找回密码：管理员重置，或服务端 CLI 强制重置。
- 管理后台可关闭注册，关闭后只能由管理员创建账号。
- 用户可被限制登录；限制后已签发会话立即失效。

### 对话

- PC Web 对话空态、会话历史、新建/重命名/删除会话。
- 模型选择、流式输出、停止生成、Markdown / 代码高亮 / 复制。
- 深度思考折叠区；上游支持 reasoning 时展示。
- 消息重试、错误态、限流与额度提示。
- 会话与用量按用户隔离。

### 管理后台

- 用户管理：列表、搜索、详情、额度、限制登录、重置密码。
- 预置厂商 + 自定义 OpenAI 兼容 API。
- Base URL / API Key / 模型列表 / 超时 / 并发 / 连接测试。
- 管理后台不读取用户对话正文；CSV 只导出账号字段。

### 服务端

- Go 1.26（GVM 管理）、`net/http` + `chi`、SQLite（MVP）。
- 密码 Argon2id 哈希；会话服务端存储。
- 上游厂商 Key 使用 AES-GCM 加密入库。
- SSE 流式代理；单二进制内嵌前端静态资源。

## 4. 明确后置（P1）

- 移动端完整适配（本轮先做 PC，布局预留响应式）。
- 文件上传、多模态、语音、联网搜索真实接入。
- 分享链接、分支对话、编辑已发送消息。
- 套餐 / 支付、邀请、用户自助注销、CSV 导出增强。
- 面向开发者的个人 API Key。
- 邮件服务（若未来需要验证或找回密码）。
- 多机部署、Redis 队列、跨厂商自动重试/负载均衡。

## 5. 当前默认假设

1. **单实例 C 端部署**：没有租户；所有用户在同一实例内，数据按用户隔离。
2. **注册默认开放**：后台提供“允许注册”开关；自用稳定后可关闭。
3. **管理员唯一**：首个注册账号为管理员，不提供多管理员/角色系统（P1）。
4. **无邮件依赖**：不做验证邮件、不用邮件找回密码。
5. **用户无 API Key**：C 端 Web 只用账号登录；厂商 Key 仅管理员可见。

## 7. 首轮验收

- 注册 → 自动登录 → 进入对话；刷新后会话保持。
- 邮箱重复、弱密码、错误密码、连续失败锁定均有明确提示。
- 未登录访问工作台自动跳转登录；管理员可进入后台。
- 管理员可查看用户列表、限制登录、重置密码、调整额度。
- 1280–1920 宽 PC 浏览器可用；1024 自动折叠侧栏。
- SSE 流式不卡顿，停止/重试/刷新恢复可用。
