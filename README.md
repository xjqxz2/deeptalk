# DeepTalk

DeepTalk 是一个 AI 对话工作台，支持多轮对话、深度思考、联网搜索、图片理解和历史会话管理。

## 访问地址

- 对话工作台：<https://deeptalk.peon.top/>

## 安装到桌面

DeepTalk 支持安装到手机桌面，安装后没有浏览器地址栏，打开更接近原生 App。

- iPhone / iPad：用 Safari 打开本页，点击底部「分享」，选择「添加到主屏幕」，再点「添加」。
- Android：用 Chrome 打开本页，点击右上角菜单，选择「安装应用」或「添加到主屏幕」。
- 电脑：Chrome / Edge 地址栏右侧出现安装图标时，点击即可安装。

也可以登录后在头像菜单里选择「安装到桌面」，按提示操作。

## 开始使用

1. 打开对话工作台，使用账号登录；没有账号可自行注册。
2. 点击「新建对话」，在输入框中提问。
3. 输入框右下角可以选择模型。
4. 按 Enter 发送，Shift + Enter 换行。
5. 回答生成过程中可以随时点击「停止生成」。
6. 回答完成后可以复制、重新生成或反馈。

## 深度思考

系统会根据问题自动决定是否思考以及思考深度，不需要手动开启或选择强度。

- 简单问题会直接回答；
- 复杂问题会自动进行更深入的推理；
- 推理过程会在回答上方展示，可展开或收起。

## 联网搜索

不需要手动开关。系统会在思考过程中判断是否需要联网、搜索什么，以及打开哪些网页。

- 需要实时信息时才会搜索；
- 回答中的 [1]、[2] 是可点击的引用编号，点击即可打开对应网页；
- 回答下方会保留模型实际查看过的网页，可展开查看；
- 不展示搜索词和搜索结果数量；
- 问候和简单短句不会触发搜索；
- 不适合搜索的问题会直接回答。

## 图片

- 点击输入框左侧的回形针上传图片；
- 也可以直接把图片粘贴到输入框；
- 支持 PNG、JPEG、GIF、WebP；
- 单张不超过 8MB，每条消息最多 4 张；
- 发送前可以预览和删除。

## 分享对话

- 打开一段对话后，点击右上角的分享图标，或在「更多」菜单里选择「分享对话」；
- 创建后会得到一条只读链接，复制发给别人即可查看；
- 拿到链接的人可以阅读消息，但不能提问、回复或重新生成；
- 想继续对话需要自己登录；
- 选择「取消分享」后，链接立即失效。

## 历史会话

- 左侧列表按时间分组展示历史对话；
- 首轮问答结束后会自动生成一个简短标题，过长时以省略号截断，悬停可看全文；
- 支持搜索、重命名和删除；
- 点击会话即可继续之前的内容。

## 账号

- 登录后可在右上角头像菜单中修改密码或退出登录；
- 忘记密码请联系平台管理员重置。

## 常见问题

**登录失败怎么办？**

请确认邮箱和密码是否正确；连续多次失败后账号会临时锁定，稍后再试。

**忘记密码怎么办？**

请联系平台管理员重置，系统不发送邮件验证码。

**回答中断了怎么办？**

可以点击回答下方的「重新生成」，或重新发送问题。

**上传图片失败？**

请确认图片格式和大小符合要求，单张不超过 8MB。

**页面显示不正常？**

建议使用最新版 Chrome、Edge 或 Safari，并刷新页面。
